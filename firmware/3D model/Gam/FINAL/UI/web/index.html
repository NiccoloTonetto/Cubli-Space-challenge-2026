Balance mode

Cornernot resolved

Calibrate re-runs the corner identification: it dots the current gravity estimate against all 8 body corners and latches the closest, which is what selects the gain matrix. Run it whenever you re-seat the cube, and check the answer matches the corner you are actually resting on before arming. Every mode change transits through IDLE (wheels stopped, disarmed, pivot re-resolved); ARM is two-step and the firmware still applies its own tilt gate on top.
